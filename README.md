# 🚨 Troubleshooting Methodology

My troubleshooting approach follows a structured methodology:

```text
1. Identify the symptom
2. Define the scope
3. Collect evidence
4. Isolate the failure domain
5. Form a hypothesis
6. Test the hypothesis
7. Identify root cause
8. Implement remediation
9. Validate service restoration
10. Document the incident
```

Typical evidence sources:

```text
show interfaces
show ip route
show arp
show mac address-table
show vlan
show spanning-tree
show etherchannel
show ip ospf neighbor
show logging
ping
traceroute
Wireshark
SNMP
Syslog
```
